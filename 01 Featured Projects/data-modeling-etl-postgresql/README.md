# Data Modeling & ETL with PostgreSQL

## Overview

Designed a PostgreSQL star schema database and built an ETL pipeline that transforms raw JSON song metadata and user activity logs into a relational database optimized for analytical queries.

## Skills Demonstrated

- Python
- SQL
- PostgreSQL
- ETL
- Database Design
- Data Modeling

## Files

- `etl.ipynb` — Development notebook
- `etl.py` — ETL pipeline
- `create_tables.py` — Database creation script
- `sql_queries.py` — SQL queries

## Key Takeaways

- Designed a dimensional database schema
- Built an automated ETL process
- Loaded structured data into PostgreSQL
- Validated database integrity using SQL
