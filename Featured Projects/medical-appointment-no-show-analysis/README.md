# Medical Appointment No-Show Analysis

## Overview

Exploratory analysis of more than 100,000 medical appointments to identify factors associated with patient no-shows.

- Python
- Pandas
- Exploratory Data Analysis
- Data Visualization
- Healthcare Analytics

- `Investigate_a_Dataset.html` — HTML version

## Key Takeaways

- Cleaned and explored healthcare data
- Investigated patient attendance patterns
- Created visualizations to identify trends
- Communicated findings through written analysis
