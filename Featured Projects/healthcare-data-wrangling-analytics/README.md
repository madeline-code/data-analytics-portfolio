# Healthcare Data Wrangling & Analytics

## Overview

This project combines CMS Medicare utilization data with U.S. Census demographic data to explore factors associated with preventable healthcare utilization. The project demonstrates the complete data wrangling process, including data collection, cleaning, transformation, merging, analysis, and visualization.

## Skills Demonstrated

- Python
- Pandas
- API Integration
- Data Wrangling
- ETL
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Healthcare Analytics

## Files

- `Final Notebook.ipynb` — Jupyter notebook
- `Final Notebook.html` — HTML version of the notebook

## Key Takeaways

- Gathered data from multiple sources
- Cleaned and merged datasets
- Created visualizations
- Answered a healthcare research question using demographic and utilization data
